# Evaluacion2

## Descripción
Programa en Python que utiliza la API de GraphHopper para calcular rutas
entre dos coordenadas geográficas y mostrar instrucciones de navegación
en español.

## Requisitos
- Python 3
- Biblioteca requests
- API Key de GraphHopper

## Configuración
Configurar la variable de entorno GRAPHHOPPER_API_KEY con una API Key válida.

## Ejecución
Instalar la dependencia:

    python3 -m pip install requests

Ejecutar el programa:

    python3 graphhopper_directions.py

Ingresar las coordenadas de origen y destino en formato latitud,longitud.
Para salir, escribir s o salir.
